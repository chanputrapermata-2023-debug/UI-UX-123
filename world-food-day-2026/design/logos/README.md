# Logo resmi (wajib dari panitia)

Letakkan file logo **resmi dari link di juknis lomba** di folder ini dengan nama:

- `kemendikdasmen.png`
- `seameo.png`
- `seameo-recfon.png`

Pakai PNG berlatar transparan. Saat dirender, logo dipasang dengan tinggi 72 px dan lebar mengikuti proporsi asli file. Jangan memotong, meregangkan, mewarnai ulang, atau memberi efek pada logo.
Selama file belum ada, desain menampilkan kotak placeholder bergaris putus-putus.
